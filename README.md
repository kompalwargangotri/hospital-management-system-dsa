# Hospital Management System — DSA and StreamlitnnA dual-implementation Hospital Management System designed to showcase key **Data Structures** concepts (specifically **Singly Linked Lists**). This repository contains:nn1. **C++ Console Application**: A terminal-based menu-driven implementation.n2. **Python Streamlit Dashboard**: An interactive, modern web application that ports the C++ linked list structures to Python and displays the data in a beautiful dashboard.nn---nn## 🚀 Live DemonnOnce you deploy this repository to Streamlit Cloud, it will be available at a public URL for anyone to try.nn---nn## 📷 Screenshotsnn### 📊 Dashboard Overviewnn![Dashboard Overview](screenshots/dashboard_overview.png)nn### 📋 Patient Database (Linked List)nn![Patient Database](screenshots/patient_database.png)nn### 🩺 Registered Doctors Directorynn![Doctors Registry](screenshots/doctors_registry.png)nn### 🛏️ Hospital Bed Status & Allocation Viewnn![Bed Management](screenshots/bed_management.png)nn### 🚪 Bed Allocation Dropdown (Linked Patient Data)nn![Bed Admission Dropdown](screenshots/admit_patient_dropdown.png)nn---nn## 🛠️ Data Structures ImplementednnThis project showcases memory management and linear data structures using custom-built linked lists (no standard collection libraries like STL or python lists for storage):nn- **Patient LinkedList**: Stores patients dynamically. Supports `Add Patient` (append node to tail), `Display Patients` (traverse list), and `Delete Patient` (delete by ID, handling pointer re-linking for head, middle, and tail cases).n- **Doctor LinkedList**: Stores doctor details including specialization and availability.n- **Bed Management**: Controls hospital bed capacity limits and handles dynamic patient check-ins/check-outs.nn---nn## 📂 Project Structurenn``````textnhospital-management-system-dsa/n├── .github/workflows/n│   └── tests.ymln├── cpp/n│   └── hospital_management.cppn├── screenshots/n│   ├── dashboard_overview.pngn│   ├── patient_database.pngn│   ├── add_patient.pngn│   ├── delete_patient.pngn│   ├── doctors_registry.pngn│   ├── bed_management.pngn│   └── admit_patient_dropdown.pngn├── tests/n│   └── test_repository.pyn├── .gitignoren├── app.pyn├── requirements.txtn├── requirements-dev.txtn└── README.mdn├── Hospital_Management.cpp   #
